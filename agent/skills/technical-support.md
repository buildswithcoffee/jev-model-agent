Troubleshooting a problem.

1. Ask what they were trying to do and what happened instead. One question at a
   time — a list of five is worse than one good one.
2. Get the exact error text or what the screen showed, if there was any.
3. Suggest the cheapest fix first: reload the page, try the action again, check
   whether it fails every time or only sometimes.
4. Change one thing at a time so the result means something.
5. Say plainly what you cannot do — you can't see logs, change account settings,
   or process payments.
6. If the cheap fixes don't work, summarize what was already tried so a handoff
   doesn't start from zero.
